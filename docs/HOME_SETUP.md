# Подготовка домашнего ПК — пошагово

Цель: дома «скачал → собрал → играешь». Первый запуск занимает несколько
часов (сборка библиотек), дальше всё летает.

## Что нужно

| Требование | Значение |
|---|---|
| Система | Windows 10/11 x64 |
| Диск | ~20 ГБ свободного (лучше 40+) |
| Память | ≥6 ГБ свободной во время сборки данных |
| Клиент | Ashes of Creation (Steam) — у вас уже есть |
| Интернет | нужен один раз: winget, vcpkg, NuGet, Go modules |

> Код SandalCore собран под сборку клиента **2026-01-29**. Если игра
> обновится — скрипт предупредит (`WARNING: this client is not the build
> this code was made for`). Тогда обновите проект: `git fetch upstream &&
> git merge upstream/main` (или скачайте свежий ZIP) и соберите заново.

## Шаг 1. Скачать проект

Три варианта, от простого к полному:

- **A. ZIP (для «просто поиграть»):** GitHub → репозиторий OaC-ru →
  Code → Download ZIP → распаковать куда угодно. Пуш не нужен.
- **B. HTTPS clone:** `git clone https://github.com/zxDOOMxz/OaC-ru.git`
  (читать можно; пушить — только через токен).
- **C. SSH (для разработки с домашнего ПК):** см. раздел
  «SSH-ключ для дома» в конце. Если на репозитории остался deploy key от
  22.06.2026 и его приватная часть лежит на домашнем ПК — уже работает.

## Шаг 2. Убедиться, что игра найдётся

Стандартная Steam-папка находится автоматически. Если нет:

```bat
setx GAME_ROOT "D:\...\Ashes of Creation\Game"
```

Папка должна содержать `AOCClient.exe` и папку `AOC` (это папка `Game`,
не лаунчер). После `setx` откройте **новое** окно терминала.

## Шаг 3. Поставить зависимости

Запустите в папке проекта:

```bat
install_dependencies.bat
```

Проверит и предложит доставить недостающее через winget (спрашивает
перед каждой установкой): VS2022 Build Tools (нагрузка C++), CMake, Git,
vcpkg, Go, .NET 8 SDK, Python, Docker Desktop. Уже установленное
пропускает. После установки откройте новое окно (обновится PATH).

Можно сначала просто посмотреть, чего не хватает: `install_dependencies.bat -CheckOnly`.

## Шаг 4. Собрать всё

```bat
build_all.bat
```

1. Сначала извлечёт данные из вашего клиента (~10 мин на быстром ПК):
   `content.db` (311 МБ), навигационную сетку `area_nav.bin` (974 МБ) +
   `area_geom.bin` (232 МБ), таблицы, полы городов.
2. Потом соберёт серверные программы в `dist\Release` (tether_server,
   launcher, worldd). **Первый раз долго**: vcpkg компилирует grpc,
   protobuf, openssl из исходников — часы. Повторные сборки — секунды.

⚠️ **Navmesh обязателен**: без `dist\content\area_nav.bin` у всех мобов
0 HP и урон не работает. `build_all.bat` строит его сам.

Если мало памяти: `build_all.bat -Jobs 4`.

## Шаг 5. Запустить

```bat
launch_worldd.bat
```

- Docker Desktop должен быть **запущен** (PostgreSQL + NATS в контейнерах).
- Первый раз Windows спросит про доверие локальному сертификату
  (`certs\`) — выбрать **Да/Yes**.
- Откроется окно лаунчера: логин → «Keep me signed in» (чтобы входить
  автоматически) → **LAUNCH GAME**.

## Шаг 6. Чек-лист проверки

- [ ] Персонаж создаётся, мир Verra грузится
- [ ] Ходьба, бег, прыжки
- [ ] Бой с мобами: урон, HP, всплывающие цифры
      (если у всех 0 HP — не собран navmesh, шаг 4)
- [ ] NPC: диалоги, магазины, продажа/ремонт
- [ ] Крафт на станциях
- [ ] Маунт (наземный/летающий/водный)
- [ ] Сбор ресурсов: деревья, камни, травы
- [ ] Города: полы твёрдые (стены и лестницы пока без коллизий —
      известный баг, см. KNOWN_ISSUES.md)

## Шаг 7. Второй игрок (дети)

- **LAN:** второй запуск клиента в той же сети.
- **Через интернет:** проще всего VPN — **Tailscale** (поставить на ваш
  ПК и устройствам детям, одна сеть, ничего не настраивать) или
  WireGuard. Распишем детально под ваш сценарий, когда дойдём.

## Если что-то пошло не так

| Видите | Причина | Что делать |
|---|---|---|
| `The Ashes of Creation client was not found` | игра не найдена | шаг 2 (GAME_ROOT) |
| у мобов 0 HP | нет navmesh | `extract_game_data.bat` (без `-Skip navmesh`) |
| `Missing: Python / .NET / Go` | не на PATH | `install_dependencies.bat` + новое окно |
| CMake: файлы из клиента отсутствуют | собрали до данных | `extract_game_data.bat`, потом сборка |
| `waiting: ...` на шаге карты | мало свободной RAM | закрыть игру/сборку; ждёт сам до 40 мин |
| CUE4Parse не скачался | нет сети | подключиться и повторить |
| сертификат не принят | отклонили CA | перезапустить, выбрать Да |

Подробности: README.md (разделы 2–4) и KNOWN_ISSUES.md.

## SSH-ключ для дома (если будете разрабатывать с него)

```bat
ssh-keygen -t ed25519 -C "aoc-home-pc"
type %USERPROFILE%\.ssh\id_ed25519.pub
```

1. Скопировать строку из вывода `type`.
2. GitHub → OaC-ru → Settings → Deploy keys → Add deploy key
   (галочка **Allow write access** обязательна).
3. Если ключ уже где-то используется на GitHub — сгенерируйте с другим
   именем: `ssh-keygen -t ed25519 -f %USERPROFILE%\.ssh\aoc_home -C "aoc-home-pc"`
   и добавьте в `~/.ssh/config`:

```
Host aoc-home-github
  Hostname github.com
  User git
  IdentityFile ~/.ssh/aoc_home
```

4. В проекте: `git remote set-url origin git@github.com:zxDOOMxz/OaC-ru.git`

Рабочий цикл: дома `git pull` → собрал/протестировал → `git push`;
на работе `git pull` → анализ/правки → `git push`.
