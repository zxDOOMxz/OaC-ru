# Семейный план: локальный сервер Ashes of Creation

Обновлено: 27 октября 2026

## Смысл проекта

Официальные серверы Ashes of Creation закрыты. Поднимаем локальный сервер
на базе SandalCore, чтобы играть с детьми (дети — в другом городе,
подключение через интернет).

## Что изменилось с первоначального плана

- **SandalCore ушёл далеко вперёд.** Майлстоуны 1–8 и 10 готовы:
  подключение, персонажи, мир, статы, таланты, инвентарь, **бои и
  способности всех классов**, живые NPC с AI (агро/лиш), маунты (наземные,
  летающие, водные), сбор ресурсов и 22 профессии. В работе — города и
  цивилизация (майлстоун 9). Следующий — квесты (майлстоун 11).
- **AoC-RiseOfPhoenix удалён с GitHub** (нет ни форков, ни копии в
  веб-архиве). Не критично: SandalCore покрывает всё нужное.
- Наша задача — не писать бои с нуля, а **собрать, запустить и
  тестировать**, а дальше помогать апстриму (квесты, баги из KNOWN_ISSUES).

## Дорожная карта

1. **Дома**: установить зависимости (`install_dependencies.bat`).
2. **Дома**: собрать всё (`build_all.bat`) — извлечёт данные из клиента
   и соберёт сервер. Navmesh (`dist\content\area_nav.bin`, ~1.2 ГБ)
   обязателен: без него у мобов 0 HP и бой не работает.
3. **Дома**: запустить (`launch_worldd.bat`), зайти в игру, проверить
   мир, бой, крафт, маунтов.
4. **Мультиклиент**: сначала LAN, потом через интернет (VPN — самый
   простой способ, например Tailscale или WireGuard).
5. **Вклад в проект**: майлстоун 11 (квесты) или исправление багов из
   KNOWN_ISSUES.md.

## Роли машин

| Машина | Роль | Инструменты |
|---|---|---|
| Рабочий ПК | анализ кода, правки, доки, коммиты | Git, редактор (VS/CMake нет) |
| Домашний ПК | сборка, запуск, тесты | VS2022, CMake, vcpkg, Go, .NET 8, Python, Docker, клиент AoC |

## Требования сборки (домашний ПК)

- Windows 10/11 x64; ~20 ГБ свободного места; ≥6 ГБ свободной RAM
- Клиент Ashes of Creation (Steam, сборка 2026-01-29) — уже есть
- VS2022 Build Tools (рабочая нагрузка C++), CMake 3.25+, Git, vcpkg,
  Go 1.27+, .NET 8 SDK, Python 3.10+, Docker Desktop (PostgreSQL + NATS)
- `install_dependencies.bat` сам проверит и поставит недостающее
  (через winget, спрашивая перед каждым пунктом)

## Работа с репозиторием

- `origin` — наш форк: github.com/zxDOOMxz/KAmesh1
- `upstream` — cyborqz/SandalCore
- Синхронизация с апстримом:

```bat
git fetch upstream
git merge upstream/main
```

- Рабочий процесс: правки с работы → commit → push → вечером дома pull →
  собрать → протестировать → пушить фиксы.
